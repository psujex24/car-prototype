Czołgi – Lokalny Multiplayer 3D w Unity 🎮🛠️

Prosty, ale satysfakcjonujący projekt lokalnego multiplayera 3D stworzony w Unity jako część kursu Unity. Gracze wcielają się w czołgistów i sterują swoimi pojazdami na torze pełnym przeszkód i autonomicznych pojazdów AI.

🎮 Na czym polega gra?

- Lokalny multiplayer dla dwóch graczy
- Każdy gracz steruje czołgiem, który musi przejechać przez tor
- Inne pojazdy poruszają się samodzielnie z wykorzystaniem prostej AI
- Możliwość zmiany widoku kamery (pierwszo- i trzecioosobowy)
- Gra w trybie split-screen

🔹 Funkcje gry

- 🚗 Sterowanie ręczne czołgiem (dwuosobowy multiplayer)
- 💥 Kolizje z przeszkodami i AI
- 🧠 AI – pojazdy poruszające się automatycznie
- 🕹️ Walidacja skręcania (skręcasz tylko w trakcie jazdy)
- 🎮 Split-screen lokalny multiplayer
- 🔄 Widok z pierwszej i trzeciej osoby
- 🧱 Tor z przeszkodami i logicznym układem

🧰 Technologie

- Unity 6000.0.44f1
- C#
- System wejścia z klawiatury
- Prosty system AI
- Rigidbody + Collider

📦 Uruchamianie lokalnie

1. Sklonuj repozytorium:
   git clone https://github.com/psujex24/car-prototype.git

2. Otwórz projekt w Unity (zalecana wersja: 6000.0.44f1)

3. Uruchom główną scenę (np. `MainScene.unity`)

4. Graj z kolegą – wystarczy jedna klawiatura 😎

✅ Status projektu

Projekt został zakończony jako część kursu Unity. Ma charakter edukacyjny i pokazuje podstawy lokalnego multiplayera oraz AI w prostym środowisku 3D.
